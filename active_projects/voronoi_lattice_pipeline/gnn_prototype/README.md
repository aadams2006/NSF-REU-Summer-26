# GNN Prototype

This folder keeps the Voronoi lattice GNN prototype organized by purpose.

## Layout

- `colab_gnn_stiffness_prototype.py`
  - Core prototype training and inference workflow.
- `notebooks/`
  - Colab notebooks grouped by experiment or test.
- `outputs/`
  - Saved run artifacts grouped by experiment or test.
- `GCN_Optimization/`
  - Optimization and architecture-comparison runners plus notes.

## Notebook and Output Groups

- `baseline`
- `richer_features`
- `richer_features_multi_seed`
- `richer_graph_features`
- `richer_graph_features_multi_seed`
- `richer_graph_features_target_normalized`
- `richer_graph_features_target_normalized_multi_seed`
- `architecture_comparison`
- `architecture_comparison_multi_seed`
- `optimization`
